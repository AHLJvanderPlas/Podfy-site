Comment fonctionne la démo

Vous jouez les deux rôles.

Rôle 01 · Vous, sur votre téléphone

Le chauffeur

Ouvrez le lien de téléversement, pointez l'appareil photo sur n'importe quel document, un ticket de café convient, et appuyez sur envoyer. C'est tout ce que le chauffeur a à faire.

Utilise : l'appareil photo de votre téléphone · GPS, si vous l'autorisez

Rôle 02 · Vous, sur cet écran

Le répartiteur

Basculez vers le portail de livraison dans un autre onglet et regardez le PDF estampillé apparaître avec la référence, les coordonnées GPS et l'horodatage, l'enregistrement qu'une équipe d'exploitation rechercherait demain.

Utilise : ce navigateur · même stockage UE qu'en production

Le parcours complet en quatre étapes

01 — Côté chauffeur

Ouvrir le formulaire de téléversement chauffeur

Saisissez un numéro de référence facultatif ci-dessus et appuyez sur Ouvrir le téléversement. Vous verrez la page de téléversement telle qu'un chauffeur la voit, un seul bouton, sans connexion. Photographiez n'importe quel document : un bon de livraison, cette page, votre main.

Vous verrez : un écran d'appareil photo à un bouton, personnalisé avec l'identifiant de démo.

02 — Envoi

Appuyer sur envoyer

Votre position est demandée lorsque vous appuyez sur envoyer, si vous accordez la permission, les coordonnées GPS sont ajoutées au tampon. Saisissez un numéro de référence si vous le souhaitez, ou laissez vide. Le téléversement se termine en quelques secondes sur une connexion 4G standard.

Vous verrez : une barre de progression du téléversement, puis une confirmation « Envoyé ».

03 — Côté bureau

Regardez-le arriver dans le portail

Ouvrez le portail de livraison dans un onglet séparé. Votre téléversement apparaît en quelques secondes, avec l'horodatage, l'étiquette GPS et un PDF estampillé téléchargeable.

Vous verrez : une nouvelle ligne dans le portail, référence, GPS, horodatage, PDF téléchargeable.

04 — Côté chauffeur

Le chauffeur reçoit sa propre copie

Si vous avez renseigné le champ Copie e-mail lors du téléversement, un PDF de confirmation personnalisé arrive à votre adresse, le même enregistrement qu'un vrai chauffeur reçoit et peut consulter à nouveau sur delivery.podfy.net via lien magique.

Vous verrez : un e-mail de confirmation personnalisé arriver à l'adresse que vous avez saisie.

Honnêteté sur la démo

Ce qui est réel, ce qui est un modèle.

Réel

  • Stockage UE-WEUR et flux d'estampillage
  • Le PDF que reçoit le bureau
  • GPS, horodatage et l'historique via lien magique

Modèle

  • L'identifiant de marque (votre identifiant client réel est différent)
  • Toute image téléversée: supprimée automatiquement sous 24 heures
  • Les notifications par e-mail en dehors du champ Copie e-mail
