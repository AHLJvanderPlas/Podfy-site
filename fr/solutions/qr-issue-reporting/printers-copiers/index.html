PODFY Signalement QR · Équipement de bureau

Un code d'erreur sur l'imprimante ?
Scan, photo, signalé.

Les problèmes d'imprimante sont signalés sous la forme "l'imprimante est encore en panne". Un QR code sur chaque appareil permet aux collaborateurs de signaler le bourrage, le toner ou le code d'erreur exact avec une photo de l'écran, et le service d'assistance sait de quel appareil il s'agit.

Demander une démo →Comment fonctionne le signalement QR

Le code d'erreur est affiché. Il figure rarement dans le ticket.

Les prestataires d'impression gérée et les services informatiques gèrent des centaines d'appareils. La plupart des tickets arrivent sans numéro d'appareil ni code d'erreur, et le premier échange consiste à savoir quelle imprimante et ce qu'affiche l'écran.

PODFY Signalement QR donne à chaque appareil son propre QR code. Les collaborateurs le scannent, choisissent le problème et photographient l'écran. Le signalement arrive avec l'appareil, l'emplacement et le code d'erreur, prêt pour le technicien ou le support.

PODFY n'interroge pas l'appareil à distance. Il rend le signalement humain complet.

  • QR code par appareil avec emplacement
  • Catégories pour papier, toner, erreurs et qualité
  • Photo du code d'erreur à l'écran
  • Signalements vers le support ou le prestataire d'impression
  • Webhook vers votre outil de support informatique
  • Historique par appareil
Les signalements servent aux pannes et aux consommables. En cas de surchauffe ou d'odeur de brûlé, prévenez directement les services généraux.

Pour démarrer

Votre liste d'équipements en entrée, des autocollants en sortie

  1. Téléchargez le modèle et renseignez les numéros, noms et emplacements de vos équipements, ou exportez-les depuis votre propre système.
  2. Importez-le dans PODFY. Chaque numéro d'équipement devient la référence d'un QR code dédié.
  3. Imprimez les autocollants. Un par équipement, avec votre logo et votre propre texte, par exemple "Un souci d'imprimante ? Scannez pour signaler".
  4. Collez-les, c'est prêt. Les signalements arrivent avec l'équipement déjà identifié.

FAQ

Questions sur les imprimantes et copieurs

Le support peut-il recevoir les signalements dans son propre outil de ticketing ?

Oui. Les signalements sont envoyés par e-mail et peuvent être transmis par webhook à votre outil de support informatique, pour arriver sous forme de ticket.

La photo de l'écran est-elle obligatoire ?

Vous le décidez par formulaire. Pour les imprimantes, une photo est souvent utile car elle capture le code d'erreur exact.

Comment ajouter nos machines ou équipements ?

Téléchargez le modèle d'équipements, renseignez les numéros, noms et emplacements, puis importez-le. Chaque numéro d'équipement devient la référence d'un QR code dédié.

Faut-il une appli ou un compte pour signaler ?

Non. On scanne le QR code avec l'appareil photo du téléphone et le formulaire s'ouvre dans le navigateur. Pas d'appli, pas de connexion, pas de compte.
